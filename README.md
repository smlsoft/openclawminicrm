## คุณสมบัติทั้งหมด

### 1. 🗨️ Multi-Panel Chat — เปิดหลายแชทพร้อมกัน

**เปิดได้สูงสุด 4 สนทนาพร้อมกัน** — LINE, Facebook, Instagram เรียงข้างกัน ไม่ต้องสลับแอป

| ช่องทาง | สี | รับ | ตอบ | ส่งได้ |
|---------|-----|-----|-----|--------|
| 💚 LINE OA | เขียว | ✅ | ✅ | ข้อความ · รูป · สติกเกอร์ · วิดีโอ · เสียง · ตำแหน่ง · Flex |
| 💙 Facebook | น้ำเงิน | ✅ | ✅ | ข้อความ · รูป (เร็วๆ นี้) |
| 💜 Instagram | ม่วง-ชมพู | ✅ | ✅ | ข้อความ · รูป (เร็วๆ นี้) |

- **Multi-Panel** — เปิด 4 จอพร้อมกัน แยกสีตาม platform ชัดเจน
- **Reply-first** — ตอบ LINE ภายใน 25 วิ = **Reply API ฟรี!** หมดเวลา = fallback Push อัตโนมัติ
- **แสดง ✓ฟรี / push** ทุกข้อความ — รู้ค่าใช้จ่ายทันที
- **สติกเกอร์ LINE ฟรี** — 6 ชุด (Moon, Sally, Brown & Cony, CHOCO, BT21)
- **อัพโหลดรูป** — ส่งรูปให้ลูกค้าจาก dashboard
- **แชร์ตำแหน่ง GPS** — ส่ง Google Maps link
- **ข้อความใหม่กะพริบ** — จุดแดง + ไฮไลท์ ไม่พลาดลูกค้า
- **Badge "สนใจซื้อ!"** — เห็นปุ๊บรู้ว่าลูกค้าคนไหนพร้อมซื้อ
- Quick Reply — ข้อความสำเร็จรูป กดเลือกแล้วส่งทันที
- Auto-refresh ทุก 5 วินาที — real-time
- **Inbox เดิม** ยังใช้ได้ปกติ (จอเดียว + Customer Info sidebar)

### 2. 🤖 AI วิเคราะห์ทุกข้อความ — อัตโนมัติ 100%

ทุกข้อความที่ลูกค้าส่งเข้ามา AI วิเคราะห์ให้ทันที:

| วิเคราะห์ | ผลลัพธ์ | ตัวอย่าง |
|-----------|---------|---------|
| ความพอใจลูกค้า | ปกติ / ติดตาม / ไม่พอใจ | "ลูกค้าเริ่มไม่พอใจเรื่องจัดส่งช้า" |
| โอกาสซื้อ | ไม่สนใจ / เริ่มสนใจ / สนใจมาก! | "ลูกค้าถามราคาและขอใบเสนอราคา" |
| แท็กอัตโนมัติ | tags | ถามราคา, สนใจสินค้า, ร้องเรียน |
| Sales Pipeline | stages | ใหม่ → สนใจ → เสนอราคา → ปิดการขาย |

**ไม่ต้องทำอะไรเลย — AI ทำให้หมด**

### 3. 🦐 น้องกุ้ง — AI Advisor 5 บทบาท + Deep Loop Analysis

น้องกุ้งทำงาน **24/7 อัตโนมัติ** ไม่ต้องสั่ง:

| บทบาท | ทำงาน | หน้าที่ |
|-------|-------|---------|
| 🚨 **Problem Solver** | ทุก 1 ชม. | วิเคราะห์ปัญหาลูกค้า → หาต้นเหตุ → 5 ทางออก → เลือกดีสุด → action steps |
| 💰 **Sales Hunter** | ทุก 1 ชม. | หาลูกค้าที่อยากซื้อ → กลยุทธ์ปิดการขายแบบไทย |
| 👥 **Team Coach** | ทุก 6 ชม. | วิเคราะห์ทีม → แผนพัฒนารายบุคคล |
| 📊 **Weekly Strategist** | จันทร์ 08:00 | สรุปสัปดาห์ → กลยุทธ์สัปดาห์หน้า → Monday Action |
| ❤️ **Health Monitor** | ทุก 3 ชม. | Health Score 0-100 → ตรวจจับลูกค้าเสี่ยงก่อนหาย |

**Deep Loop Analysis:**
```
ปัญหา → ต้นเหตุ → 3-5 ทางออก → เลือกดีสุด → Action Steps ทำได้ทันที
    ↑                                                      ↓
    └──── ถ้ายังไม่ชัด วนซ้ำจนได้ข้อสรุป ────────────────────┘
```

ถ้าพบ CRITICAL → **ส่ง Telegram แจ้งเตือนทันที!**

### 4. 🦐 น้องกุ้งตอบแทนอัตโนมัติ + AI ตอบแทน 5 นาที

น้องกุ้งตอบแชทลูกค้าแทนพนักงานได้ — **ฟรี ไม่เสียเงิน!**

| Mode | พฤติกรรม |
|------|---------|
| **ปิด** | หูทิพย์ — ฟังอย่างเดียว ไม่ตอบ (default) |
| **อัตโนมัติ** | ตอบทุกข้อความอัตโนมัติ (ยกเว้นพนักงาน) |
| **เรียกชื่อ** | ตอบเมื่อลูกค้าเรียก "น้องกุ้ง" |
| **Keyword** | ตอบเมื่อมี keyword ที่กำหนด เช่น "ราคา", "สั่ง" |

**AI ตอบแทน 5 นาที (ใหม่!):**
- ไม่มีใครตอบ 5 นาที → AI ตอบให้อัตโนมัติ (เฉพาะ 1-on-1 ไม่ตอบในกลุ่ม)
- ขึ้น "🤖 ตอบอัตโนมัติ" ชัดเจน ลูกค้าไม่สับสน
- ใช้ข้อมูลจาก **Knowledge Base + Memory** ตอบแม่นยำ
- Admin ตอบก่อน → ยกเลิก AI ทันที

---

### 4.1 💡 AI แนะนำคำตอบ

กดปุ่ม 💡 → AI วิเคราะห์บทสนทนาแล้วแนะนำ **2-3 คำตอบ** พร้อม:
- **เหตุผล** ว่าทำไมควรตอบแบบนั้น
- **Tone:** เป็นมิตร / มืออาชีพ / เร่งด่วน / เห็นอกเห็นใจ
- **Priority:** สูง / กลาง / ต่ำ
- ปุ่ม **"ใช้เลย →"** + **"📋 Copy"**
- ดึงข้อมูลจาก KB + Memory + Skill Lessons มาแนะนำ

---

### 4.2 📚 Knowledge Base (KM) — ฐานความรู้สำหรับ AI

ใส่ข้อมูลสินค้า ราคา โปรโมชั่น เงื่อนไข FAQ → AI ดึงไปตอบลูกค้าอัตโนมัติ

| หมวด | ตัวอย่าง |
|------|---------|
| 📦 สินค้า | รุ่น A ราคา 12,900 บาท กรอง 4 ขั้นตอน |
| 🏷️ โปรโมชั่น | มี.ค. ลด 20% เฉพาะรุ่น B |
| 📋 นโยบาย | เปลี่ยนคืนภายใน 7 วัน |
| ❓ คำถามบ่อย | ใช้กับน้ำประปาได้ไหม? |
| 🚚 จัดส่ง | ส่งฟรีทั่วประเทศ Kerry 2-3 วัน |
| 💳 ชำระเงิน | โอน/PromptPay/ผ่อน 0% |

- **Qdrant Cloud** — Semantic vector search (ค้นหาตามความหมาย)
- **Gemini Embedding** — สร้าง vector อัตโนมัติ
- **เปิด/ปิด** ได้ — โปรหมดกดปิด AI ไม่ดึงไปใช้
- **ยิ่งละเอียด AI ยิ่งตอบแม่น**

---

### 4.3 🧠 AI Learning — เรียนรู้ไปเรื่อยๆ ยิ่งใช้ยิ่งฉลาด

**Customer Memory (จำลูกค้ารายคน):**
- AI สรุปทุก 10 ข้อความ → เก็บ insight ประหยัด token
- จำ: สไตล์, ความสนใจ, วิธีตอบที่เหมาะ, เคยซื้ออะไร

**Skill Lessons (เรียนรู้จากสำเร็จ/ล้มเหลว):**
- ลูกค้าซื้อ → AI จำว่า "ตอบราคาชัด + บอกผ่อน → ปิดได้"
- ลูกค้าชม → AI จำว่า "ตอบเร็ว + ใส่ใจ → ประทับใจ"
- ลูกค้าร้องเรียน → AI จำว่า "ตอบช้า + ไม่ขอโทษ → ไม่พอใจ"
- สร้าง **กฎ** ใช้ได้กับลูกค้าคนอื่นด้วย (Global Skills)

**ปุ่ม 🧠 ในหน้า Chat** — ดู Memory + Skills ของลูกค้าแต่ละคน

### 6. 👥 CRM อัตโนมัติ — ไม่ต้องกรอกข้อมูลเอง

- ลูกค้าทักมา → ระบบสร้างข้อมูลลูกค้าอัตโนมัติ
- ดึงรูป + ชื่อจาก LINE/Facebook/Instagram อัตโนมัติ
- AI ให้คะแนน sentiment + โอกาสซื้อ อัตโนมัติ
- Pipeline: ใหม่ → สนใจ → เสนอราคา → ต่อรอง → ปิดการขาย
- มูลค่า Deal + วันที่คาดว่าจะปิด + เหตุผลปิดได้/ไม่ได้

### 7. 📈 KPI พนักงาน — รู้ว่าใครทำงาน ใครไม่ทำ

| KPI | วัดอะไร |
|-----|---------|
| เวลาตอบเฉลี่ย | พนักงานตอบลูกค้าเร็วแค่ไหน (เร็ว/กลาง/ช้า) |
| จำนวนลูกค้าที่ดูแล | แต่ละคนดูแลลูกค้ากี่ราย |
| อัตราปิดการขาย | ปิดได้กี่ % จากทั้งหมด |
| ลูกค้าหลุด | เคยคุยแล้วหายไป > 7 วัน |
| เสี่ยงหลุด | ไม่มีข้อความ 3-7 วัน (เตือนก่อนหลุด!) |
| รายได้ | Pipeline รวม / ปิดได้ / ปิดไม่ได้ |
